# Ammar Website

Arabic-first bilingual landing page for the Ammar home-services app.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

The Vite base path is configured for the `muhamad-ammar-dev/Ammar` repository.

```bash
npm run deploy
```

This builds the site and publishes the generated `dist` directory to the `gh-pages` branch. Android app packages are distributed separately through GitHub Releases.
